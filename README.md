# Regenmeter Peumans Landkracht

Neerslag sinds 1 januari in Grote-Spouwen (eigen weerstation aangevuld met modeldata) en Romershoven, de verwachting voor de komende dagen en een inschatting van de berijdbaarheid van het land. De pagina wordt dagelijks automatisch bijgewerkt met gegevens van Open-Meteo en Weathercloud. Bekijk ze op https://jorispeumans.github.io/regenmeter/
